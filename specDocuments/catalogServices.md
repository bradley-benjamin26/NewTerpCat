# Catalog Services
The different features available to the user

## Requesting

There are a variety of request options available to a user. If the item is a physical (print) item, the user can request the book so that it is held at the circulation desk for them which is handled by the Alma system. If the item is a book chapter or article from a physical item, they can request that the library provide them a scan of that content using the interlibrary loan forms.

If it is available from the University System of Maryland and Affiliated Institutions, they can request the item to be sent to the UMD Libraries for pick up which is handled by Alma.

If the it is available only from a Big Ten Academic Alliance item, they can request the item or a scan via interlibrary loan.

## Citation generator
Creates citations for materials in the catalog in the top used citation styles.

## Favorites
Allows a user to save items to view later
