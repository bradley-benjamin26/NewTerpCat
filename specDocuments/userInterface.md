# TerpCat UserInterface

## Homepage
* Centered search-box. Should be where users' eyes go first.


## Search Results Screen

### Filters
Provides options to limit searches based on format and subject term. Includes an option to limit based on a date range.

### Results List
The main content of the page. Displays a list of the search results. Includes an image of the book cover, the title, the author, the publication date. It lists if the book is available or not and where. If it is available at UMD and is physically available, it should list the call number. The user should be able to request the book, if able to, from the search results screen.

### Transparency Panel
Displays the relevancy scoring logic to the users. Explains what was factored into the score and the actual points it received for each condition

## Item page
Accessible when a user clicks on the search result for that item. Displays full details for the item including subject terms, availability, publication information, and so on.

## About page
A page linked to from the home page. It describes what NewTerpCat is and how it works.

## Relevancy configuration page
A separate page that provides the user with the different options to fine tune the relevancy ranking algorithm
