# Covers Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show a book cover on each search result and on the item page.

**Architecture:** The backend adds `isbns` to every parsed record. A client component, `Cover`, tries Syndetics and then
Open Library for the first ISBN, and renders nothing when neither has a cover. The results list and the item page render it.

**Tech Stack:** FastAPI + pytest (backend, `uv run pytest`), Next.js + Vitest + Testing Library + axe (frontend, `npm test`).

**Spec:** `docs/superpowers/specs/2026-10-15-covers-design.md`

## Global Constraints

- Syndetics URL: `https://proxy-na.hosted.exlibrisgroup.com/exl_rewrite/syndetics.com/index.php?client=primo&isbn={isbn}/SC.JPG`
- Open Library URL: `https://covers.openlibrary.org/b/isbn/{isbn}-M.jpg?default=false`
- ISBN = first entry of `isbns`, text before the first space (`"9780143127550 (paperback)"` → `9780143127550`).
- A loaded image with `naturalWidth === naturalHeight` is the Syndetics placeholder.
- `alt=""`, `loading="lazy"`, fixed width: about 60 px on results, about 120 px on the item page.
- WCAG 2.2 AA; every render test runs axe. Use the frontend-design skill for styling.

## Review Focus

- Open Library cover that happens to be square: treated as missing, so nothing is shown. Acceptable; no test.
- Search records from the Big Ten catalogs: they go through the same `_record`, so they carry `isbns`; covered by Task 1's test using `parse_response`.
- A record whose ISBN changes while mounted (client navigation between item pages): Cover must restart at Syndetics. Task 2 test `restarts on new isbn`.
- ISBN with a qualifier: Task 2 test `strips the qualifier`.
- Narrow screens (320 px): cover stacks above the result text, no horizontal scroll. Checked by hand in Task 3.

### Task 2: Cover component

**Files:**
- Create: `frontend/app/Cover.tsx`
- Test: `frontend/tests/cover.test.tsx`

**Interfaces:**
- Produces: `export default function Cover({ isbns, className }: { isbns: string[]; className?: string })`, a `"use client"` component rendering one `<img>` or `null`.

- [ ] **Step 1: Write the failing tests**

Query the image with `container.querySelector("img")` (an `alt=""` image has no accessible role). Simulate a load with
`Object.defineProperty(img, "naturalWidth", { value: w })` (and `naturalHeight`) then `fireEvent.load(img)`.

| Test | Assertion |
|------|-----------|
| `shows the Syndetics cover first` | `src` = Syndetics URL for `9781421437576`; `alt` is `""`; `loading` is `"lazy"` |
| `strips the qualifier` | isbns `["9780143127550 (paperback)"]` → `src` contains `isbn=9780143127550/SC.JPG` |
| `keeps a tall Syndetics image` | load 100×150 → `src` still Syndetics |
| `switches to Open Library on a square placeholder` | load 100×100 → `src` = `https://covers.openlibrary.org/b/isbn/9781421437576-M.jpg?default=false` |
| `switches to Open Library on an error` | `fireEvent.error` → Open Library `src` |
| `renders nothing when both fail` | error, then error → no `img` |
| `renders nothing without an ISBN` | isbns `[]` → `container` empty |
| `restarts on new isbn` | error, then `rerender` with another ISBN → Syndetics `src` for the new ISBN |
| `has no accessibility violations` | `axe(container)` has no violations (same helper the other tests use) |

- [ ] **Step 2: Run them, see them fail**

Run: `cd frontend && npx vitest run tests/cover.test.tsx`
Expected: FAIL, cannot resolve `../app/Cover`

- [ ] **Step 3: Implement `Cover`**

State is the index of the source in use (0 Syndetics, 1 Open Library, 2 none), reset when the ISBN changes (use `key`
on the `<img>` plus state keyed to the ISBN, or `useState` reset in render; pick the simplest that passes `restarts on new isbn`).
`onLoad`: square → next source. `onError`: next source.

- [ ] **Step 4: Run them, see them pass**

Run: `cd frontend && npx vitest run tests/cover.test.tsx`
Expected: PASS
